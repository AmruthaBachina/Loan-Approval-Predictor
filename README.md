# Loan-Approval-Predictor
Intern ID: CITS1152

## 📌 Project Overview
This Machine Learning project predicts whether a loan application will be approved or rejected based on applicant details.

The project uses Python, Pandas, NumPy, Matplotlib, and Scikit-learn.

---

## 🚀 Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab

---

## 📂 Dataset
The dataset contains:
- Applicant Income
- Loan Amount
- Credit History
- Gender
- Education
- Marital Status
- Property Area

---

## ⚙️ Project Workflow
1. Data Loading
2. Data Cleaning
3. Data Analysis
4. Data Visualization
5. Model Training
6. Loan Prediction

---

## 📊 Features
- Loan approval prediction
- Missing value handling
- Data visualization
- Machine learning model
- Prediction analysis

---

## 📸 Output
The model predicts whether the loan application will be approved or not.
